## 4. Project Objectives

The main objectives of the Student Study Planner are:

1. To develop a simple web-based study planning application.
2. To help students organize their academic tasks.
3. To allow users to manage subjects and study activities.
4. To provide deadline tracking.
5. To allow students to monitor completed and pending tasks.
6. To provide a simple progress dashboard.
7. To store user information securely.
8. To demonstrate the software development lifecycle from requirements to testing and evaluation.

---

## 5. Target Users

The primary users of the system are students.

Students can use the application to:

- Manage subjects.
- Create study tasks.
- Set deadlines.
- Track task completion.
- Monitor study progress.

The initial version will focus on individual student users.

---

## 6. System Overview

The application will follow a basic web application architecture.

The general flow will be:

**User → Web Interface → Application Logic → Database**

The user interacts with the web interface. The application processes the user's requests and stores or retrieves information from the database.

### Main Components

1. User Interface
2. Authentication Module
3. Subject Management Module
4. Task Management Module
5. Progress Tracking Module
6. Database Module
