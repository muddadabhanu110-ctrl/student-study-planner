## 1. Introduction

The Student Study Planner is a web-based application designed to help students organize their academic activities in a simple and structured way. Students often need to manage multiple subjects, assignments, study tasks, deadlines, and completed activities. Managing these activities manually can make it difficult to keep track of important tasks.

The proposed system provides a centralized platform where students can create and manage subjects, add study tasks, set deadlines, update task status, and monitor their study progress.

The project is designed as a beginner-friendly software application that demonstrates important software development concepts such as requirements analysis, system architecture, database management, programming, testing, debugging, and project documentation.

---

## 2. Project Overview

The Student Study Planner will provide students with an easy-to-use interface for organizing their study activities.

The system will allow users to:

- Create an account and log in.
- Add and manage subjects.
- Create study tasks.
- Assign deadlines to tasks.
- Update task information.
- Mark tasks as completed.
- Delete unnecessary tasks.
- View pending and completed tasks.
- Monitor overall study progress.

The system will use a database to store user, subject, and task information.

---

## 3. Problem Statement

Students may have difficulty managing multiple subjects and academic tasks using notebooks, scattered notes, or different applications.

Common problems include:

- Forgetting assignment or study deadlines.
- Difficulty organizing tasks by subject.
- Lack of a centralized study-planning system.
- Difficulty identifying pending tasks.
- Difficulty tracking completed study activities.

The Student Study Planner aims to provide a simple solution by bringing these activities into one application.
