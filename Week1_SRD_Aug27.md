## 10. Scope of the Project

### 10.1 In-Scope Features

The first version of the project will include:

- User registration.
- User login.
- Subject management.
- Study task management.
- Deadline management.
- Task completion tracking.
- Progress dashboard.
- Database storage.
- Basic authentication.

---

## 11. Out of Scope

The following features will not be included in the initial version:

- Online video classes.
- Online examinations.
- Payment processing.
- Teacher management.
- University management.
- Social networking.
- Real-time messaging.
- Advanced AI-based personalized learning.
- Mobile application.

These features may be considered as future enhancements.

---

## 13. System Constraints

The project has the following constraints:

- The project is designed for a junior developer.
- Development time is limited.
- The initial application will focus on basic study-management features.
- The system will use a lightweight database.
- Advanced AI features are outside the initial project scope.
- The application may require an internet connection depending on the deployment environment.

---

## 14. Assumptions

The project is based on the following assumptions:

- Users have basic computer or smartphone knowledge.
- Users will provide valid information during registration.
- Users will enter accurate task and deadline information.
- The system will initially support individual student users.
- The number of users will be limited during the initial development stage.

---

## 15. Risks and Mitigation

| Risk | Impact | Mitigation |
|---|---|---|
| Incorrect user input | Medium | Use input validation |
| Data loss | High | Perform regular database backups |
| Software bugs | Medium | Conduct systematic testing |
| Security issues | High | Implement authentication and secure password handling |
| Development delays | Medium | Prioritize core features |
| Poor user experience | Medium | Keep the interface simple and perform usability testing |
